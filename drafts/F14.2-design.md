## Settings

(move r, order o in {A move then table, B table then move}, key length L 1-26): 1.45 million per text. For each, the
24 known places land on carved places `land[e]` and key slots `slot[e]` (0252's `move_setting`). Two known places in
one slot give a check (carved letters c1, c2; known letters p1, p2).

Dedupe per text: the result depends only on the multiset of checks (c1, c2, p1, p2) and, for the key-word step, on the
slot of each known place. Hash the sorted check list; decide each distinct list once.

## Alphabet tests (exact)

Precompute, for each of the 208,064 alphabets A (0109's dictionary keyword alphabets plus standard and KRYPTOS), the
26 x 26 table D_A[x][y] = pos_A(y) - pos_A(x) mod 26 as uint8 (208,064 x 676 bytes = 141 MB, shared by fork).

- One alphabet (0109's 10 classes): W on both sides, added: D_W[c1][c2] == D_W[p1][p2] for every check; Beaufort:
  D_W[c1][c2] == -D_W[p1][p2]. W on one side with standard or KRYPTOS on the other: the fixed side's differences are
  constants. Vectorised over all W: one gather per check, `all` over checks (about 1 ms per check list).
- Two alphabets (0244's index): a pair (PA, CA) fits when D_CA[c1][c2] == s * D_PA[p1][p2] for every check
  (s = 1 added, -1 Beaufort). Key each CA by its first k check differences (k = min(4, checks)) as one int, sort;
  key each PA the same way, `searchsorted`; verify the remaining checks on the candidate pairs. About 15 ms per check
  list (numpy, 208,064 alphabets).

## Key word (decides lengths where pairs fit by chance)

Expected chance fits for two alphabets are 4.3 x 10^10 / 26^c for c checks: none below about 7 checks, thousands at
3-4. A fit forces key values at the covered slots; check them against every rotation of every dictionary and puzzle
word of length L (numbered on standard, KRYPTOS, the plain or the cipher alphabet, any shift), as 0244 did, through an
index keyed by the forced values at the first three covered slots. Settings with fewer than 3 covered slots: counted
only, as 0244 counted 25-26.

## Texts and verdict

K4, 50 shuffles (counts per (o, L) class compared, K4's rank), and plants: two random dictionary alphabets, a random
move and order, a random dictionary key word of length L; found when its pair fits and its key word is recovered
(at least 2 plants per length band 6-10, 11-18, 19-24). A K4 key-word fit is decrypted in full and submitted.
